# BB_Foodly - Food Ordering Web Application

## 1. Project Overview

BB_Foodly is a full-stack food ordering web application developed using Django and MySQL.

The main purpose of this project is to provide an online platform where users can:

- Create an account
- Login and logout
- Browse restaurants
- Browse food categories
- Search for food items
- Filter food by cuisine and price
- View restaurant menus
- Add food items to cart
- Increase or decrease food quantity
- Remove items from cart
- Add delivery addresses
- Delete delivery addresses
- Place food orders
- Select payment methods
- View order details
- Track order status
- Add food items to wishlist/favorites
- View previous orders

The project provides a complete food ordering flow from browsing food to placing and tracking an order.

# 18. Order Status

The application supports multiple order statuses.

### PLACED

The customer has successfully placed the order.

### CONFIRMED

The restaurant has confirmed the order.

### PREPARING

The restaurant is preparing the food.

### OUT_FOR_DELIVERY

The food has been handed over for delivery.

### DELIVERED

The customer has received the order.

### CANCELLED

The order has been cancelled.

# 40. Order Placement

When the user places an order:

1. The selected address is checked.
2. An order is created.
3. Cart items are converted into order items.
4. Food quantities are stored.
5. Payment method is stored.
6. The order status is set to `PLACED`.
7. Cart items are removed.
8. The user is redirected to the order success page.

The order creation process uses Django database transactions.

# 59. Database Transaction

Order creation uses a database transaction.

The transaction ensures that order creation and order-item creation happen together.

If an error occurs during the transaction, the database can roll back the changes.

This helps maintain data consistency.
